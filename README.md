# dates

## 1. 目的と手段

`dates` は、デートを成功させるための攻略システムではない。

**目的と手段を混同しない。**

### 目的

この世界で目指すものは、Agentが答えを出すことではない。

- 自分で考えられること
- 自分で判断できること
- 自分で行動できること
- 経験から自分なりに学べること
- 他者との関係の変化を、自分なりに理解していくこと

その結果として、親密度が変化することもある。
しかし、親密度を最大化すること自体を唯一の目的にはしない。

**目的は、自分と他者との関係の中で、自分自身が考え、選び、成長していくこと。**

### 手段

Agentはそのための補助線である。

- 観察する
- 客観化する
- 会話を分析する
- 選択肢をつくる
- 可能性を想像する
- 計画を助ける
- 行動の結果を振り返る

Agentは判断を奪わない。

**助ける。でも決めない。**

```text
                目的
                 ↓
        自分で考え、選び、成長する
                 ↑
                 │
              手段
                 │
        Agent / Chat / Date / Odekake
```

---

## 2. Agentは助けるだけ

Agentが賢くなることをゴールにしない。

Agentが「正解」を知っている世界でもない。

他者の気持ちは完全にはわからない。未来もわからない。だからAgentは、観測できた事実と、そこから考えられる仮説を分ける。

```text
観測
 ↓
客観化
 ↓
仮説・可能性
 ↓
選択肢
 ↓
       自分が判断
          ↓
        行動
          ↓
        経験
          ↓
        学習
          ↓
      次の自分
          ↺
```

**Agentが成長するのではなく、Agentを使った自分が成長する。**

---

## 3. 手段としてのChat / Date / Odekake

それぞれは目的ではなく、関係や経験を変化させる手段として扱う。

| 手段 | 扱うもの | 役割 |
|---|---|---|
| Chat | 会話・反応・言葉 | 関係を観察し、会話を変える |
| Date | 共有する時間 | 二人の経験をつくる |
| Odekake | 移動・場所・体験 | 次の体験を組み立てる |
| Agent | 客観化・想像・整理 | 自分の判断を助ける |

Chatだけでも親密度は変わる。
Dateをしなくても関係は変化する。
Odekakeをしても、必ず親密になるとは限らない。

だから、これらを「親密度を上げる機械」として一つに潰さない。

---

## 4. 親密度は目的の一つだが、答えではない

親密度そのものを直接取得することはできない。

会話、反応、時間、行動、共有した体験などから、状態を仮説として捉える。

```text
観測できるもの
  ↓
会話 / 反応 / 行動 / 時間 / 体験
  ↓
解釈
  ↓
親密度の仮説
  ↓
次の可能性を想像する
```

「親密度83点」のような断定ではなく、

> 今はこう見える。
> ただし、別の可能性もある。

という形にする。

「わからない」は欠陥ではない。

**わからないから、自分で考える余地がある。**

---

## 5. コンバージョンの先にあるもの

マーケティングでは、認知、興味、検討、コンバージョン、離脱という概念で人の行動を捉える。

しかしデートは、単純なファネルではない。

```text
好感
 ↓
期待
 ↓
葛藤
 ↙   ↘
進みたい  戻りたい
 ↘       ↙
  もう一度考える
       ↓
   もっと / もう
```

好きだから進むとは限らない。
好きだから迷うこともある。

「もう帰りたい」も失敗ではない。

**離れることも含めて、自分で判断した経験である。**

---

## 6. 最短ではゴールに着かない

デートの価値は目的地だけにない。

寄り道、偶然、待ち時間、どうでもいい会話、少し遠回りした道。その途中で二人の状態が変化していく。

**必要な摩擦まで消してはいけない。**

Agentは最短ルートだけを出すのではなく、複数の可能性を示す。

最後にどれを選ぶかは、自分で決める。

---

## 7. わくわくを共有する

デートでは、未来を一方的に決めるのではなく、二人で想像する。

「ここ行ってみようか」

「このあと面白いところあるよ」

「もう少し歩いてみる？」

Agentが全部を決めてしまったら、この余白がなくなる。

だから、Agentは**次の可能性を少しだけ見せる**。

全部を決めない。

---

## 8. 自分が成長していく物語

`dates` の主人公はAgentではない。

**自分である。**

最初は迷ってもいい。
Agentに整理してもらってもいい。
選択肢を出してもらってもいい。

でも、最後は自分で選ぶ。

選んだ結果を経験する。

そして、次は少し違う選び方ができるようになる。

```text
      Agent
        │
        │ 助ける
        ↓
      自分
        │
        │ 判断する
        ↓
      行動
        │
        │ 経験する
        ↓
      学ぶ
        │
        │ 変化する
        ↓
    次の自分
```

この循環こそが、この世界の物語である。

**Agentが人間を最適化するのではない。人間が、自分自身を少しずつ理解していく。**

---

## 9. Blueprint — すべてがある世界

`dates` の世界には、Chat、Date、Odekake、場所、作品、会話、期待、葛藤、親密度、離脱、想像、計画がある。

しかし、それらは目的そのものではない。

それぞれが、自分と他者との関係を経験し、自分自身の判断を育てるための手段になりうる。

```text
                 ┌── Chat
                 │
                 ├── Date
                 │
自分 ──→ Agent ──┼── Odekake
                 │
                 ├── 想像
                 │
                 └── 計画
                         ↓
                       行動
                         ↓
                       経験
                         ↓
                     自分の変化
                         ↓
                      次の判断
                         ↺
```

目指すのは「相手を攻略するAgent」ではない。

**わからない他者との関係を客観化し、可能性を想像し、それでも最後は自分で判断して生きていく。そのためのAgentである。**

これは実装仕様ではなく、`dates` が今後どんな機能やAgentを生み出しても戻ってこられるための**世界観・Blueprint**である。
